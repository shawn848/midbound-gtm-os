Search intent is the purpose behind a user's query. It describes what the searcher is trying to accomplish, not just the words they typed. Search engines and AI models use intent classification to match queries with the most relevant type of content.

## How It Works

Search intent falls into four primary categories:

- **Informational**: The user wants to learn something. Example: "what is person-level visitor identification." These queries call for educational content like blog posts, glossary definitions, and guides.
- **Navigational**: The user wants to find a specific page or brand. Example: "MidBound login" or "HubSpot pricing." These queries target branded pages.
- **Commercial**: The user is researching before a purchase decision. Example: "MidBound vs Snitcher" or "best visitor identification tools 2026." These queries call for comparison pages, reviews, and feature breakdowns.
- **Transactional**: The user is ready to take action. Example: "MidBound free trial" or "visitor identification tool signup." These queries target product pages, demo booking forms, and registration flows.

AI answer engines interpret intent differently than traditional search. When someone asks ChatGPT "how does website visitor identification work," the AI model synthesizes a comprehensive answer from multiple sources rather than returning a list of links. This means the content that gets cited needs to match the intent precisely. A page optimized for transactional intent will not get cited for an informational query, even if it mentions the right keywords.

For B2B content strategy, mapping each piece of content to a specific intent type ensures you are creating the right format for the right stage of the buyer journey. Glossary terms match informational intent. Comparison pages match commercial intent. Product pages match transactional intent.
