# Pre-Publish Checklist -- MidBound

Run this checklist on every piece of content before presenting it as final. If any critical item fails, fix it before publishing.

## Voice Match

- [ ] Correct founder loaded (Sebastian vs. Eli -- they are NOT interchangeable)
- [ ] Sounds like the founder, not like a content machine
- [ ] Matches the founder's natural paragraph structure (Sebastian: 1-2 sentences; Eli: 2-4 sentences)
- [ ] Opening line matches the founder's hook style
- [ ] Closer matches the founder's style (Sebastian: command; Eli: "Prove me wrong." or thesis)

## Structure and Style

- [ ] Lowercase first word (unless proper noun or "I")
- [ ] "I" always capitalized (I'm, I'll, I've, I built)
- [ ] No em-dashes
- [ ] No quotation marks around phrases
- [ ] Numbers as numerals (10, not ten; $50K, not fifty thousand)
- [ ] Whitespace between paragraphs (especially for Sebastian)
- [ ] Platform-appropriate length (see platform playbook)

## Anti-Slop Check

- [ ] No authority signaling phrases ("The uncomfortable truth", "Let me be clear")
- [ ] No narrator setup lines ("Here's the thing about...")
- [ ] No dramatic rhetorical framing ("And that's when it clicked.")
- [ ] No three parallel dramatic sentences
- [ ] No bookend summary (restating the opening thesis at the end)
- [ ] No self-branded concepts ("This is what I call...")
- [ ] No hype words ("game changer", "revolutionary", "next-level")
- [ ] No "no fluff" disclaimers
- [ ] No transition padding ("With that being said...")
- [ ] Fewer than 3 slop patterns detected (if 3+, full rewrite required)

## Substance

- [ ] At least one specific example with concrete details (numbers, features, scenarios)
- [ ] Product claims match what's in `knowledge/` files
- [ ] Reasoning or consequences shown (not just conclusions)
- [ ] Practical value or lesson for the reader
- [ ] No generic statements that could apply to any product

## Safety

- [ ] No competitor customer names
- [ ] No competitor internal metrics claims
- [ ] No compliance claims (GDPR, CCPA) unless founder-verified
- [ ] No guaranteed results
- [ ] No specific match rate claims unless founder-verified
- [ ] Privacy concerns handled thoughtfully (Eli's framing)
- [ ] Pattern vs. person test passed (critique approaches, not people)
- [ ] Integration partner names used positively or neutrally (HubSpot, Slack)

## Platform-Specific

### LinkedIn
- [ ] Hook earns the "see more" click
- [ ] No hashtags in body (zero to one at end, if any)
- [ ] No bold text (use whitespace for structure)
- [ ] No engagement bait closer

### X/Twitter
- [ ] Each tweet under 280 characters
- [ ] First tweet stands alone
- [ ] Thread is 7 tweets or fewer
- [ ] No over-hashtagging

### Reddit
- [ ] Post delivers value without MidBound mention
- [ ] MidBound mentioned once, naturally, not in first paragraph
- [ ] No link to MidBound in post body
- [ ] Title is specific, not clickbait

### Blog
- [ ] Frontmatter complete (title, slug, author, date, pillar, SEO fields, tags, status)
- [ ] SEO title under 60 characters
- [ ] Meta description under 155 characters
- [ ] 800-1500 words
- [ ] H2/H3 structure for sections
- [ ] CTA with trial link at end
